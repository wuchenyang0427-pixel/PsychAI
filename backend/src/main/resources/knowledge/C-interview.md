# C 层知识卡：评估访谈要收集哪些信息

> 用于信息收集阶段：判断"还该问什么"，以及"信息够不够下结论"。
> 每轮对话只在信息明显不足时注入本卡，避免助手一上来就查户口。

## 一、六个必问维度（缺一项就不要下严重程度结论）

| 维度 | 要问到的内容 | 常见的问法 |
| --- | --- | --- |
| 具体表现 | 情绪低落、兴趣减退、焦虑、烦躁、失眠、食欲变化、注意力下降、躯体不适 | "最近有没有觉得做什么都提不起兴趣？" |
| 持续时间 | 是几天、几周还是几个月；是否几乎每天都出现 | "这种状态大概持续多久了？" |
| 功能损害 | 对工作/学习、社交、睡眠饮食的影响程度 | "这些有没有影响到你的工作或和朋友相处？" |
| 触发因素 | 具体事件或长期压力源 | "最近有没有发生什么特别的事？" |
| 既往与应对 | 以前是否出现过、是否就诊或咨询过、自己试过什么方法 | "之前有过类似的感觉吗？试过什么办法？" |
| 支持系统 | 是否有可依靠的亲友、是否独居、是否有人知道 | "身边有能说说话的人吗？" |

此外必须覆盖风险项（见 A 层）：自杀意念、自伤、伤人、物质使用。

## 二、时间与功能的判断要点

- 抑郁症状的持续时间是区分"情绪波动"和"需要干预的抑郁发作"的关键。临床诊断通常要求症状持续
  至少两周，且造成明显痛苦或功能损害；持续时间越短、功能损害越轻，越倾向于自我调节。
- 焦虑若表现为对多个领域的长期、难以控制的担忧，病程通常以"月"为单位，而不是"几天"。
- 判断严重程度时，"功能损害"比"症状数量"更能决定转介紧迫性：能照常上学上班 vs 已经请假躺床，
  是完全不同的处置。
- 单次量表得分不能代替病程：一个月的轻度失眠和两周的完全失眠，处理方式不同。

（本节的病程阈值属于通用临床常识，不在本知识库论文范围内，需专业人员复核。）

## 三、必须考虑的身体与物质因素

出现抑郁/焦虑表现时，需要排除或考虑这些常见"模仿者"：

- 躯体疾病：甲状腺功能异常、贫血、慢性疼痛、围绝经期、产后；
- 物质与药物：酒精、戒断反应、糖皮质激素、部分降压药、兴奋剂使用后回落；
- 睡眠障碍：睡眠呼吸暂停、长期倒班；
- 哀伤反应：近期丧失亲人，需要与抑郁发作区分；
- 双相：曾经有过持续数天的精力旺盛、睡眠需求减少、话多、冲动消费等，会影响治疗方案。

## 四、提问节奏

1. 先共情、再提问：每条提问前先回应对方刚才说的内容，不要连续追问。
2. 一次只问一个维度，问完等回答再继续。
3. 对方回避的问题不要强行追问，先记录"未收集到"，并在生成报告时如实说明信息不足。
4. 风险问题要在建立了基本信任之后再问，但**不能因为"还没聊熟"就一直不问**。

## 五、信息不足时的做法

- 明确告知需要的补充信息，并说明用途（"为了更准确地判断，我想再了解一下…"）。
- 信息不足时，报告里要写"目前信息不足以判断"，而不是给出一个勉强凑出来的严重程度。
